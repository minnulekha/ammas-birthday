🎂 Amma's Birthday Surprise
A heartfelt, interactive web experience created as a special birthday gift for my mother. This project takes her on a digital journey through cherished memories, leading up to a special message and a step-by-step gift reveal.
✨ Features
🎵 Cinematic Background Music: Sets the emotional tone right from the first interaction.
📸 Interactive Memories: Features a Polaroid gallery and a fully automated/tappable large-screen photo slideshow.
🎂 Make a Wish: A highly interactive cake section where you light the candle, tap to blow it out (complete with a smoke animation!), and swipe to cut a slice.
🎈 Balloon Pop: A fun mini-game to reveal a hidden "You Are The Best!" message.
💌 A Special Letter: An elegant, custom-styled digital envelope that opens to reveal a scrollable, heartfelt letter.
🎁 Step-by-Step Gift Reveal: Builds anticipation by taking the user through a wrapped box, the watch reveal, and a capture of the happy moment, ending with a prompt to replay the experience.
📱 Fully Responsive: Beautifully designed to work seamlessly on both mobile phones and desktop/laptop screens.
🛠️ Tech Stack
HTML5: Semantic structure and layout.
CSS3: Custom animations (flickering flames, rising smoke, falling hearts, slicing knife), elegant typography (`Playfair Display`, `Lato`, `Nanum Pen Script`), and a responsive global pop-up modal system.
Vanilla JavaScript: Handles all the interactivity, state management (e.g., ensuring the candle is blown out before cutting), slideshow logic, and sequential screen navigation.
🚀 How to Run Locally
Clone this repository to your local machine.
Ensure all assets (`song.mp3` and the various `.jpeg`/`.png` images) are in the root directory alongside the code files.
Simply double-click `index.html` to open it in your default web browser.
Note: Due to browser autoplay policies, the background music will begin as soon as the user clicks the initial "✦" spark trigger on the home screen.
📂 File Structure
`index.html`: The main structural document containing all the screen sections.
`style.css`: All styling, responsive media queries, and keyframe animations.
`script.js`: The logic driving the interactive elements, pop-ups, and screen transitions.
Assets: Requires `song.mp3`, `watch_box.png`, `watch_reveal.png`, `happy_mom.png`, `gift.png`, and `mom1.jpeg` through `mom20.jpeg`.
